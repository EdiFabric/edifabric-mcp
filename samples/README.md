# Sample EDI files

Made-up X12 files for trying the ediFabric tools and for reviewers. They contain no real people's data.

| File | What it is |
|---|---|
| `837p-claim.txt` | A valid 837P professional claim (HIPAA 5010, 005010X222A1) |
| `837p-claim-error.txt` | The same claim with errors, for validation |
| `837p-two-claims.txt` | An interchange with two 837P claims, for splitting |
| `850-purchase-order.txt` | An 850 purchase order (004010) with one line item |
